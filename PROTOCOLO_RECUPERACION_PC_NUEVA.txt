# ===============================================================================
# FHVT GALLERY AI - PROTOCOLO DE RECUPERACIÓN EN PC NUEVA
# (Guía Rápida ante Pérdida de Disco o Migración de Sistema)
# ===============================================================================

Este documento contiene las instrucciones paso a paso para restaurar y poner
en funcionamiento el proyecto completo desde GitHub en cualquier computadora nueva.

-------------------------------------------------------------------------------
1. REQUISITOS PREVIOS EN LA NUEVA COMPUTADORA
-------------------------------------------------------------------------------
1.1. Python:
     - Instalar Python 3.10 o 3.11 (x64) desde https://www.python.org/
     - IMPORTANTE: Durante la instalación, marcar la casilla:
       [X] "Add Python to PATH"

1.2. Git:
     - Instalar Git para Windows desde https://git-scm.com/

1.3. (Opcional - Para aceleración por GPU):
     - Tarjetas NVIDIA: Drivers actualizados + CUDA Toolkit (opcional).
     - Tarjetas AMD / Intel / NVIDIA: El proyecto incluye soporte universal
       automático mediante ONNX Runtime DirectML.

-------------------------------------------------------------------------------
2. PASO A PASO DE RESTAURACIÓN (3 COMANDOS)
-------------------------------------------------------------------------------

Abre una terminal (PowerShell o CMD) y ejecuta:

--- PASO 2.1: CLONAR EL REPOSITORIO ---
git clone <URL_DE_TU_REPOSITORIO_GITHUB>
cd FHVT_Gallery_AI

--- PASO 2.2: CREAR EL ENTORNO VIRTUAL E INSTALAR DEPENDENCIAS ---
python -m venv .venv

# Activar e instalar dependencias (PowerShell en Windows):
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\pip install -r requirements.txt

--- PASO 2.3: INICIAR LA APLICACIÓN ---
Doble clic en:
run_app.bat

O mediante consola:
.\.venv\Scripts\python.exe main.py

-------------------------------------------------------------------------------
3. MODELOS DE INTELIGENCIA ARTIFICIAL (DESCARGA AUTOMÁTICA)
-------------------------------------------------------------------------------
- No necesitas respaldar manualmente los gigabytes de modelos.
- En el primer inicio, main.py creará automáticamente las carpetas necesarias
  en 'models/'.
- Cada herramienta (Upscale, Quitar Fondo, Depth, Normal, SAM, Generativo)
  descargará su modelo oficial desde Hugging Face automáticamente con un clic
  desde la interfaz de usuario.

-------------------------------------------------------------------------------
4. HERRAMIENTAS DE AUDITORÍA Y VERIFICACIÓN INCLUIDAS
-------------------------------------------------------------------------------
Para verificar que toda la arquitectura, dependencias y enlaces a Hugging Face
estén 100% operativos en el nuevo equipo, ejecuta:

run_audit.bat

O mediante consola:
.\.venv\Scripts\python.exe audit_tools\run_audit_suite.py

-------------------------------------------------------------------------------
5. COMPILAR EJECUTABLE .EXE INDEPENDIENTE (OPCIONAL)
-------------------------------------------------------------------------------
El archivo de empaquetado 'FHVT_Gallery_AI.spec' ya está configurado
con todos los módulos ocultos y assets necesarios.

Para compilar un ejecutable portable en la nueva PC:
.\.venv\Scripts\pyinstaller FHVT_Gallery_AI.spec

El archivo final generado estará en:
dist/FHVT_Gallery_AI/FHVT_Gallery_AI.exe
